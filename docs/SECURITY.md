# Security notes

To repozytorium jest publicznym opisem środowiska laboratoryjnego.

## Nigdy nie publikuj tutaj
- haseł i tokenów,
- kluczy API,
- plików `.env`,
- prywatnych kluczy SSH,
- realnych publicznych adresów IP,
- domen używanych do administracji,
- eksportów konfiguracji z aktywnymi sekretami,
- danych klientów,
- pełnych logów zawierających dane osobowe.

## Screenshoty
Przed dodaniem zrzutu usuń lub zamaskuj adresy, hostnames, nazwy użytkowników, e-maile, identyfikatory urządzeń, tokeny sesyjne, klucze i hasła.
